# 📊 Sales Performance Analysis & Excel Dashboard

## 📌 Project Overview

This project focuses on analyzing **4,000 sales transactions** using Microsoft Excel and building an interactive dashboard to understand overall sales performance, profitability, regional performance, and product-category trends.

The project covers the complete workflow from **data cleaning and transformation → analysis → pivot tables → visualizations → dashboard development**.

---

## 🎯 Project Objective

The main objective of this project is to transform raw sales data into meaningful business insights using Excel.

The analysis focuses on:

* Sales performance
* Profitability
* Regional performance
* Product category performance
* Quantity sold
* Discount analysis
* Profit margin
* KPI development
* Interactive dashboard visualization

---

## 📂 Dataset

The dataset contains **4,000 sales transactions** from **2023 to 2024**.

### Main Columns

| Column           | Description                      |
| ---------------- | -------------------------------- |
| Order ID         | Unique identifier for each order |
| Order Date       | Date of the transaction          |
| Region           | Sales region                     |
| Product Category | Category of the product sold     |
| Sales Amount     | Revenue generated from the order |
| Quantity Sold    | Number of units sold             |
| Discount (%)     | Discount applied to the order    |
| Profit           | Profit generated from the order  |

---

## 🧹 Data Cleaning

Before performing the analysis, the raw dataset was cleaned and standardized.

The cleaning process included:

* Identifying inconsistent text values
* Standardizing region names
* Standardizing product category names
* Removing unnecessary spaces using `TRIM()`
* Checking for missing/blank values
* Checking data types
* Preparing the cleaned dataset for analysis

For example, inconsistent values such as different capitalization or unwanted spaces in region/category fields were standardized before creating the final analysis.

---

## 🔎 Analysis Performed

Several Excel-based analysis techniques were used to answer business questions.

### 1. Regional Sales Analysis

Sales performance was analyzed across:

* East
* North
* South
* West

This helps identify which regions contribute the most to overall revenue and profit.

### 2. Product Category Analysis

The following product categories were analyzed:

* Clothing
* Electronics
* Furniture
* Groceries
* Sports

Sales, profit, and quantity sold were compared across categories.

### 3. Profitability Analysis

Profit was analyzed by:

* Region
* Product Category
* Individual transactions

A **Profit Margin** calculation was also created to evaluate profitability relative to sales.

### 4. Discount Analysis

Discount percentages were analyzed to understand the relationship between discounts and business performance.

### 5. Quantity Analysis

Total quantity sold was calculated and compared across regions and product categories.

## 💡 Business Insights

The analysis shows that:

* **East** is the strongest region by sales.
* **Clothing** generates the highest sales among the product categories.
* **Clothing** also records the highest category-level profit.
* Regional performance is relatively competitive, with East, North, and South contributing strongly to total sales.
* The dashboard provides a consolidated view of sales, profit, quantity, regional performance, and category performance.

> Note: These insights are based on the current dataset and are intended for analytical and portfolio demonstration purposes.
